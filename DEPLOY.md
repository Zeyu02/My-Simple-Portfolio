# Commands to Push Your Portfolio to GitHub

# Connect your local repository to GitHub (replace with your actual repo URL)
git remote add origin https://github.com/Zeyu02/portfolio.git

# Push your code to GitHub
git push -u origin main

# Enable GitHub Pages
# After pushing, go to your repository settings:
# Settings → Pages → Source: Deploy from branch → Branch: main → Save

# Your portfolio will be live at:
# https://zeyu02.github.io/portfolio/
